# 米国株 資金フロー（マネーフロー）分析ダッシュボード

米国株市場におけるセクター（大分類）および個別テーマ別の**資金流出入（売買代金 × 騰落方向）**をリアルタイムに集計・可視化するダッシュボードアプリです。

---

## 📌 主な機能

1. **資金フロー ランキング**:
   - **大分類（セクター別）** および **個別テーマ別** の集計切り替え
   - **純流入 Top10** / **純流出 Top10** / 全件一覧
   - **金額順** / **流入率順** のソート
2. **直感的な視覚化**:
   - 日次資金フロー推移ミニチャート（緑：流入、赤：流出）
   - 「3日連続流入」などの連続トレンドバッジ
   - 金額表示（`$49.42B`, `-$1.34B` 等）、流入率（`+47%` 等）、1D騰落率
3. **「本物の流入だけ」フィルター**:
   - 出来高倍率が過去20日平均の1.2倍以上の確度の高い資金流入のみをワンクリック抽出
4. **銘柄ドリルダウン**:
   - 各セクター・テーマをクリックすると、内包銘柄ごとの株価・1D騰落率・推定フロー・出来高倍率を一覧表示
5. **最新市場データ自動取得**:
   - `yfinance` と連携し、ボタン1つで最新の米国株価・出来高を取得して再計算
6. **ダーク / ライトモード対応**

## 📐 資金フローの計算ロジック

本アプリでは、機関投資家の実需・マネーフローを捉えるため以下の計算式を採用しています。

$$
\text{売買代金 (Trading Value)} = \text{終値 (Close)} \times \text{出来高 (Volume)}
$$

$$
\text{価格位置係数 (Price Factor)} = \frac{\text{終値} - \text{始値}}{\text{高値} - \text{安値} + \epsilon} \quad (-1.0 \le \text{Factor} \le 1.0)
$$

$$
\text{日次資金フロー (Daily Flow)} = \text{売買代金} \times \text{価格位置係数}
$$

$$
\text{流入率 (Inflow Rate)} = \frac{\sum \text{資金フロー}}{\sum \text{売買代金}} \times 100 \ (\%)
$$

## 🚀 起動方法

### 前提条件
- Python 3.8 以上
- 必要なライブラリ: `pip install pandas yfinance`

### アプリの起動
```bash
python app.py
```
起動すると自動的にブラウザ（`http://localhost:8088`）が開き、ダッシュボード画面が表示されます。

---

## 🛠 カスタマイズ（銘柄・テーマの追加）
`fetcher.py` の `SECTOR_THEME_DEFINITIONS` 配列を編集することで、自由に対象銘柄やテーマ（ETF、個別株）を追加・調整できます。
